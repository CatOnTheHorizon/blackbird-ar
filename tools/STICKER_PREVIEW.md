# PNG 贴片构建与 v28 发布说明

本次以用户提供的 1536×1024 透明 PNG 为视觉源，不再把 ORA/JPEG 旧贴片混作新鸟身。原 PNG 是扁平拼版，鸟脚/尾与长椅相接处有绘制遮挡：局部轮廓及木板属于受限重建，不能声称恢复了被遮挡的原始像素。

## 文件与运行环境

使用 Python 3.10（已验证环境包含 Pillow、NumPy、OpenCV、SciPy）。读取下载的图像必须使用 `-I`；源图片单独放进新建空输入目录，维护脚本在项目 tools 目录，生成物在其他目录，不能在输入目录里执行解释器。

- `extract_sticker_png.py`：候选专用入口；拒绝已存在的输出目录及写入生产 assets 目录。
- `extract_sticker_static.py`：巴士、完整站牌、按轮毂居中且为旋转留出透明 padding 的两个轮子。
- `refine_bird_candidates.py`：五个鸟组，bird4 保留成鸟与小鸟为一组，接触带局部轮廓约束并输出不确定性掩膜。
- `refine_bench_candidate.py`：长椅无鸟底板，同一木板干净纹理修补接触区域，保留两处金属支撑。
- `build_sticker_preview.py`：十张 PNG/WebP + 1745×1280 场景坐标 + 带验收控件的本地 HTML 预览。
- `package_sticker_release.py`：从验收候选生成无调试控件的正式 v28 暂存目录；暂存完成后需复核再复制到生产根目录。

从项目目录之外或项目根目录执行，绝不在源图输入目录执行：

```text
C:\Users\amst\AppData\Local\Programs\Python\Python310\python.exe -I C:\Users\amst\blackbird-ar\tools\extract_sticker_png.py --source <独立输入目录>\sticker.png --out <新的候选输出目录>
```

生成后 `<输出目录>/scene/index.html` 依赖项目中的 lib 和原 target.mind（不复制或重编识别目标）；从项目根目录的本地 HTTP 服务浏览该目录。`checks` 中包含白、黑、天空、棋盘格全景、长椅单独显示及仅鸟上移 55px 的合成图。预览页面中有“正常动画 / 只看长椅 / 鸟抬起 55px”三个按钮。

## 坐标与约束

- 保持运行时 1745×1280 逻辑平面，显式映射源坐标，而不是把 1536×1024 素材表直接当目标平面。
- 鸟、椅、站牌：target = (60,220) + 1.025 × source；巴士：target = (53,238) + 1.16 × source。
- 轮子在巴士映射前移动源坐标 (+20,-40)，使其进一步嵌入车身；PNG 左轮为 wheel0，右轮为 wheel1。轮毂源坐标约 (227,491)/(653,491)，不是外框中心。
- v28 轮胎侧面及外轮廓不再随整张贴片转动；在轮毂处用源图半径 51px 的圆形正面独立旋转，等效滚动半径为 54px。转角与驶入距离一致，停车后停止旋转。`node tools/test_wheel_scene.mjs` 验证轮轴、UV 和停车行为。
- 站牌 pivot 从 metadata 读取，不再使用旧图硬编码的 x=1554。
- 这些是新画面构图，不是印刷原图的逐像素配准。新 PNG 的巴士英文与旧图不同，保持提供的画面，不自行更改。源站牌最顶端细尖已到源图边缘，不应假称恢复了边缘之外的图案。

## AR 与性能边界

- `assets/target.jpg`、`target-1024.jpg`、`target.mind` 均保持不变，构建 manifest 记录其 SHA-256。
- 桌面 VR/合成可验证贴片完整性、轮毂旋转、构图和图层；不能证明手机相机识别成功、印刷对位或真实启动耗时。
- 透明贴片无法抹掉实体纸上原本的巴士和鸟；新素材比例又不同，真实 AR 仍可能有旧图透出/重影。消除它需要另做不透明干净底板与真机验收，不应在本轮悄悄改成“已解决”。
- 保留旧版模块预载及空闲预热。候选中点击 AR 会先绘制“正在准备…”再处理音频/引擎；素材预加载失败允许重试，后续失败会释放摄像头。
- 预览上的 `window.__previewMetrics` 只记录本地按钮首帧反馈，不等于相机就绪或手机测速。

## 发布纪律

页面与 metadata 的版本都为 28，metadata 和每张 WebP 的请求 URL 均带 `?v=28`。仅给入口页面加查询参数不足以清除相对资源旧缓存。推送后须实际抓取线上页面、metadata 和十张 WebP，与本地 SHA-256 逐一比对；本地改好、提交或推送均不单独代表 Pages 已更新。

源图、放大图、原型、候选与暂存目录均由 .gitignore 排除；正式提交只包含十张生产贴片、metadata、runtime 页面、构建脚本及文档。GitHub Pages 的 v28 保留原 `target.jpg`、`target-1024.jpg`、`target.mind`，其 SHA-256 已在打包时比对一致。桌面 VR 和本地首帧按钮反馈已验收；手机相机识别、实物印刷对位及真实手机耗时仍须由用户实测。遮挡处重建及重复木纹的限制见前文，不能描述为原像素恢复。
